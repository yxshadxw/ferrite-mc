Placement handles axis, horizontal facing, slab/stair half, replaceability, waterlogging, player collision, and survival stack decrement; console commands now route through the command dispatcher and `/stop` reaches the normal shutdown path.

Integration coverage includes the original creative-break broadcast regression, streaming a changed chunk to a later joiner, reach rejection, creative placement and collision, survival timing, Commands packet filtering, console stop, and saving a bot's broken block on shutdown. Workspace-wide formatting remains affected by concurrent out-of-scope changes.

Remaining limitations requiring follow-up: the item crate currently models NBT component patches but does not provide the 26.3 component network codecs, so play `ItemStack` still rejects nonempty component patches; tool-aware survival mining is not implemented; block changes retain existing lighting rather than recomputing it. Placement currently sets a single block state and does not implement multi-block or neighbor-dependent behavior such as door halves or slab merging. Full-workspace fmt/clippy may be blocked by concurrent work in crates outside this task's ownership.
